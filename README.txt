## Windows ⇄ 手机 局域网 / 公网 文件互传（类隔空投送）

一台 Windows 电脑 + 同一 Wi-Fi 下的手机（iPhone / 安卓均可），**无需安装任何 App**，浏览器扫码即可互传文件。需要异地或手机流量访问时，打开「公网访问」开关即可一键建立公网隧道。

### ✨ 功能特性

- 📱 **手机 → 电脑**：手机页选照片 / 视频 / 文件，自动开始上传并显示真实进度，可随时取消
- 💻 **电脑 → 手机**：管理页选择文件推送，手机点「接收」，自动保存到 iPhone「文件」App 或安卓下载文件夹，大文件不再"接收失败"
- 🌐 **公网访问开关**：默认关闭（纯局域网）；打开后自动建立 Cloudflare 隧道，异地 / 手机流量也能访问，关闭即回纯局域网
- 🖥 **系统托盘常驻**：双击托盘图标打开管理页，二维码扫码即连
- 📦 **单文件 exe**：免安装、不依赖 Python，拷给同事直接双击就能用

### 📦 下载与使用

1. 下载下方附件 **AirDrop分享包.zip**，解压到电脑任意位置（如桌面）
2. 双击 **AirDrop.exe** 运行
   - 首次运行如弹出防火墙提示，勾选"专用网络"并点"允许访问"
   - 如没弹出或手机连不上，右键 `首次运行-放行防火墙.bat` → 以管理员身份运行
3. 手机连上**同一 Wi-Fi**，用相机 / 浏览器扫描管理页上的二维码
4. 在打开的手机页面里即可互传文件

### 🌐 公网访问（异地互传）

- 管理页和手机页顶部都有「**公网访问（异地互传）**」开关，**默认关闭**
- 打开后程序自动下载并启动 Cloudflare Tunnel（首次需联网下载约 30MB 组件，之后不再下载），生成 `https://xxxx.trycloudflare.com` 公网地址，二维码自动切换
- 此时手机用流量 / 在异地，扫这个二维码也能打开手机页互传
- 用完把开关拨回「关」，隧道立即关闭、回到纯局域网

### ⚠️ 注意事项

- 电脑重启后需重新运行 AirDrop.exe（本程序不是开机自启）
- 个别杀毒软件可能对单文件 exe 误报，属正常现象，选择"允许"或加入白名单即可
- 公网隧道使用 Cloudflare 免费服务，公网地址每次重新打开都会变化

### 🛠 从源码构建

源码在仓库 `airdrop/` 目录（纯 Python 标准库 + 内置 qrcode，零第三方依赖）：
Python 3.13 + `pip install pyinstaller`，运行 `python airdrop/build_exe.py` 即可打包出单文件 exe。
