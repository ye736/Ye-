AirDrop —— Windows 与手机局域网文件互传（类隔空投送）
====================================================

【这是什么】
一台 Windows 电脑 + 同一 WiFi 下的手机（iPhone / 安卓均可），无需联网、
无需安装任何 App，就能在电脑和手机之间互传文件。电脑端是一个单文件程序，
手机端用浏览器访问电脑显示的地址即可。

【系统要求】
- 电脑端：Windows 10 / 11（仅支持 Windows，依赖系统托盘）
- 手机端：任意带浏览器的手机（iPhone Safari、安卓 Chrome 等）
- 电脑和手机连到同一个 WiFi（同一局域网）

【使用步骤】
1. 把本文件夹（AirDrop.exe）复制到你电脑任意位置，例如桌面。
2. 双击 AirDrop.exe 运行。
   - 第一次运行，Windows 会弹出“是否允许此应用通过防火墙”的提示，
     请勾选“专用网络”并点“允许访问”。
   - 如果没弹、或手机连不上，请右键“首次运行-放行防火墙.bat”，
     选择“以管理员身份运行”，按提示完成。
3. 运行后，电脑右下角托盘会出现一个蓝色箭头图标：
   - 双击图标 → 打开管理页（也能看到手机要访问的地址）
   - 右键图标 → 退出程序
4. 手机连上同一 WiFi，用浏览器打开管理页上显示的地址
   （例如 http://192.168.01.x:8000），即可：
   - 手机 → 电脑：在手机页点“上传”，文件存到电脑的“接收文件夹”
   - 电脑 → 手机：在管理页把文件放进共享区，手机扫码/点链接下载
5. 接收文件夹默认在 AirDrop.exe 旁边的 Received 文件夹；
   想改位置，在管理页点“选择接收文件夹”挑选，设置会自动记住。

【注意事项】
- AirDrop.exe 是单文件、自包含程序，不依赖 Python，也无需安装，发给
  同事直接双击即可用。
- 个别杀毒软件（如 Windows Defender）可能对单文件 exe 误报，属正常现象，
  请选择“允许”或将其加入白名单即可。
- 电脑重启后需重新运行 AirDrop.exe（本程序不是开机自启）。
- 手机必须和电脑在“同一 WiFi / 同一局域网”，跨网段或热点下无法互访。

【给你的一句话】
“解压后双击 AirDrop.exe，手机连同一个 WiFi，浏览器扫/输管理页上的地址就能传文件了。”
